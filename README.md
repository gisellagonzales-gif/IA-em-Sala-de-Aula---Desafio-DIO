# IA-em-Sala-de-Aula---Desafio-DIO
Repositório de desafio em IA aplicada à educação, voltado à aplicação prática do aprendizado. Integra ChatGPT e Microsoft Copilot no planejamento de aulas, produção de materiais, internacionalização de conteúdo e adaptação para dois perfis de alunos, com atenção à autoria, ética e proteção de dados.
